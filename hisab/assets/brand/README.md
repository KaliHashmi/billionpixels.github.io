# Hisab logo

The mark is the word حساب drawn as one geometric line (ح, the three teeth of س, ا, then ب), with the dot of ب in cyan like a coin. The app icon adds HISAB underneath.

| File | Use |
|---|---|
| `hisab-icon.svg` | App icon with rounded corners (store pages, website, documents) |
| `hisab-icon-square.svg` | Full-bleed square; iOS and the stores round the corners themselves |
| `hisab-mark.svg` | The حساب mark in blue, for light backgrounds |
| `hisab-mark-white.svg` | The حساب mark in white, for blue or dark backgrounds |

Colours: gradient #2D74E6 → #1A3A9A, mark #FFFFFF, dot #34DBE7 (cyan, from the ATND palette); app primary #1E66D0.

"HISAB" is set in Montserrat ExtraBold (SIL Open Font License, commercial use allowed). It is live text in the SVGs, so install Montserrat or convert it to outlines before sending the files to a printer. The PNGs in `assets/` were exported from these files at 1024 px (48 px favicon, 384 × 192 header logo). On Android the logo is scaled to 78% so it stays inside the adaptive-icon safe zone.

Before registering the logo as a trademark, run a trademark search in Oman.
